# Stratos Utility Scripts

- **install.sh** - Installation script
- **test-all.sh** - Run all tests
- **reorganize.sh** - Project reorganization script (this script)

## Usage

```bash
# Install Stratos
./scripts/install.sh

# Run tests
./scripts/test-all.sh

# Run tests with verbose output
./scripts/test-all.sh -v
```
