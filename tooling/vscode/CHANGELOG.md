# Change Log

All notable changes to the "stratos-laguage" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.1] - 2026-01-08

### Added
- Syntax highlighting for `.st` files.
- Basic code snippets for Stratos language.
- "Stratos Dark" color theme.
- Language Server Protocol (LSP) client integration for features like:
    - Code completion
    - Diagnostics (errors, warnings)
    - Go to definition
    - Hover information
- Configuration options for Stratos compiler path and maximum problems to report.
