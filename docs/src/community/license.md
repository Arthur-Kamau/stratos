The Stratos project uses different licenses for different components:

**Full License:** [MIT](https://opensource.org/licenses/MIT)

**License:** MIT License

- ✓ Free to use in your projects
- ✓ Free to modify

**Full License:** [MIT](https://opensource.org/licenses/MIT)

## Why Different Licenses?

We use different licenses for different components to:

1. **Compiler (Apache 2.0)**: Provides patent protection and ensures the compiler remains open source
2. **Standard Library (MIT)**: Allows maximum flexibility for users to include the stdlib in any project
3. **Examples (MIT)**: Ensures developers can freely use example code without restrictions

## Third-Party Dependencies

Stratos uses various third-party libraries and tools. Each dependency maintains its own license:

- Check individual dependency licenses in their respective repositories
- View dependency information: `stratos get --info`

## Using Stratos in Your Project

### For Applications

If you're building an application with Stratos:
- ✓ Your code can use any license you choose
- ✓ The compiled output is yours
- ✓ No license restrictions on your binary

### For Libraries

If you're building a Stratos library:
- ✓ Choose any license for your library code
- ✓ Consider using MIT for maximum compatibility
- ✓ Document your license choice clearly

### For Commercial Use

Stratos is free for commercial use:
- ✓ No license fees
- ✓ No royalties
- ✓ No attribution required (but appreciated)

## Contributing
