# Stratos Community

Welcome to the Stratos community! We're excited to have you here.

## Get Involved

### 💬 Join the Discussion

- **Discord**: [Join our Discord server](https://discord.gg/stratos) - Chat with other developers, ask questions, and share your projects
- **GitHub Discussions**: [Participate in discussions](https://github.com/stratos-lang/stratos/discussions) - Propose features, share ideas, and help shape the future of Stratos
- **Twitter**: Follow [@stratoslang](https://twitter.com/stratoslang) for updates and news

### 🐛 Report Issues

Found a bug or have a feature request?
- [Open an issue on GitHub](https://github.com/stratos-lang/stratos/issues)
- Check existing issues first to avoid duplicates
- Provide clear reproduction steps and environment details

### 🤝 Contribute

Want to contribute to Stratos?
- Read our [Contributing Guide](/community/contributing)
- Check out [open issues](https://github.com/stratos-lang/stratos/issues)
- Start with issues labeled `good first issue`

## Project Repository

The Stratos repository contains:

- **Compiler** (`interpreter/C++/`) - The Stratos compiler implementation
- **Standard Library** (`std/`) - Core functionality and modules
- **Design Documents** (`design/`) - Language specifications and design decisions
- **Samples** (`samples/`) - Example projects and templates
- **Tooling** (`tooling/`) - IDE plugins and development tools
- **Documentation** (`docs/`) - This documentation site

See the [repository README](https://github.com/stratos-lang/stratos) for detailed folder structure.

## Code of Conduct

We are committed to providing a welcoming and inclusive community. Please:

- **Be respectful** - Treat everyone with respect and kindness
- **Be inclusive** - Welcome newcomers and diverse perspectives
- **Be constructive** - Provide helpful feedback and suggestions
- **Be patient** - Remember that everyone is learning

Unacceptable behavior will not be tolerated. If you experience or witness unacceptable behavior, please contact the maintainers.
